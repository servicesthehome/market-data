# market-data runner

A workflow that, when started manually or through the API (`workflow_dispatch`), downloads public spot market
data (Binance and the other public venues listed in `venues.mjs`) and sends it to one address. No dependencies;
Node built-ins only. `venues.mjs` is generated by the server's `tools/build-runner.mjs`; copy it as it is.

## Setup (in your own account and repository)
1. Create a public repository from the template you were given ("Use this template"), or add `run.mjs`,
   `venues.mjs` and `.github/workflows/run.yml` from this folder yourself. Keep the default branch named `main`.
2. Settings → Actions → General: allow actions; disable workflows from fork pull requests.
3. Settings → Secrets and variables → Actions → add `ENDPOINT`, `SIGNING_KEY` (form `key-id:key`) and
   `MEMBER_ID` (given to you privately; never commit them).
4. Create a fine-grained token (Settings → Developer settings → Fine-grained tokens) limited to this repository
   with Repository permissions → "Actions: Read and write", the longest expiry, and hand it over privately.
   It only allows starting this workflow.
5. Protect the default branch (no direct pushes).

The script prints only `ok` or a short error code.
